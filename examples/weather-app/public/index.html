Weather Bot

Demo app backed by Iriguchi via the weather-bot agent. The chat lives behind the Ask AI button on the right edge, rendered by @iriguchi/chat-ui.

Everything on this panel is registered as an iri_context slice and re-derived on every message. route, city and today are scalars, so they ride in the agent's prompt every turn; the 7-day forecast is an array, so it costs nothing until the agent reads it with get_context.

There is no API key on this page. The browser posts to this app's own /api/ask-ai, which is where the gateway key lives.
